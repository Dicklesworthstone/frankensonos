# Notes, 2026-10-26
# The player only speaks SMB when the getaa URL carries NO port; with an
# explicit port it sends `HEAD /S HTTP/1.1` to that port and never reaches
# libsmb2. So the harness must serve on 445 (root) and omit the port.
# With this impacket build the client's SMB1 NEGOTIATE carries a dialect list
# impacket rejects ("SMB2 not supported, fallbacking"), so the session falls
# back to SMB1 and the patched smb2QueryInfo never runs - the art is still
# served (200) but the FileAllInformation over-read is not exercised.
# Forcing SMB2 by patching the dialect check makes the session 404 instead.
# Net result at the daemon level: no DOWN for any N, i.e. the over-read costs
# the request, never the daemon.
